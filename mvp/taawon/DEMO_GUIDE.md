# دليل العرض التقديمي للمستثمرين (Investor Demo Guide)
## منصة «تعاون» (Taawon) — منظومة التأهيل الذكي للتربية الخاصة

---

### 1. بيانات الدخول السريع (Demo Credentials)
> **كلمة المرور الموحدة لجميع الحسابات:** `Taawon@2026`
> صفحة تسجيل الدخول (`/login`) تحتوي على **أزرار الدخول السريع بنقرة واحدة (One-Click Login)** لتجنب أي ارتباك أثناء العرض.

| الدور (Role) | البريد الإلكتروني | الاسم التجريبي | السيناريو أثناء العرض |
|---|---|---|---|
| **مدير المركز (Admin)** | `admin@taawon.app` | د. فهد العتيبي | لوحة المؤشرات، اعتماد الخطط الذكية، توزيع الأخصائيين |
| **أخصائي نطق وتخاطب (Speech)** | `speech@taawon.app` | سارة الخالدي | مراجعة التقرير الذكي الأولي، صياغة التقرير العيادي |
| **أخصائي سلوكي (Behavior)** | `behavior@taawon.app` | أحمد الدوسري | مراجعة مقاطع الفيديو المنزلية وتقييمها بالنجوم والملاحظات |
| **أخصائي تربية خاصة (Special Ed)** | `specialed@taawon.app` | ريم الشمري | إدارة الجلسات الحضورية ومتابعة التقدم |
| **ولي الأمر (Parent)** | `parent@taawon.app` | خالد المنصور (والد ريان) | تبديل الأبناء، إنجاز المهام اليومية، الاستشارة الفورية مع مساعد الذكاء الاصطناعي |

### 2. مسار العرض التقديمي (5-Act Investor Demo Flow)

#### المشهد الأول: المشكلة والحل (The Hook & Landing Page)
- **الرابط:** `http://localhost:3000/`
- **رسالة العرض:** مراكز التربية الخاصة تعاني من تشتت التواصل بين 3 أطراف (الإدارة، الأخصائيين، أولياء الأمور)، وتأخر خطط التأهيل لأسابيع. «تعاون» تجمع الأطراف الثلاثة مدعومة بوكيل ذكاء اصطناعي (AI Agent) يُسرّع التشخيص ويحوّله لخطة أسبوعية قابلة للتطبيق في المنزل.
- **استعرض:**
  - أرقام المنصة في الصفحة الرئيسية.
  - الركائز الست لمسار التأهيل.
  - إمكانية التبديل بين اللغتين (العربية RTL والإنجليزية LTR) بنقرة واحدة.

#### المشهد الثاني: بوابة ولي الأمر والمساعد الذكي (Parent Experience)
- **تسجيل الدخول:** اضغط على زر "دخول كولي أمر (Parent)" من صفحة الدخول.
- **ما تعرضه للمستثمر:**
  1. **مبدّل الأبناء (Child Switcher):** أظهر للمستثمر أن العائلة يمكن أن تتابع أكثر من طفل بسلاسة من القائمة العلوية (مثال: ريان وسارة).
  2. **مسار التأهيل (Rehabilitation Stepper):** وضوح المرحلة الحالية للطفل (جمع البيانات -> تقرير الذكاء الاصطناعي -> مراجعة الفريق -> الخطة المعتمدة).
  3. **المهام اليومية (`/parent/tasks`):**
     - استعراض مهام اليوم المنزلية (نطق، سلوك، مهارات يومية).
     - تجربة الضغط على "إرسال مقطع فيديو" لإظهار نافذة رفع الفيديو التدريبي للأخصائي.
  4. **المستشار الذكي للأسرة (`/parent/chat`):**
     - افتح الدردشة واضغط على أحد الاقتراحات السريعة (مثل: *"كيف أتعامل مع نوبة الغضب عند قطع الآيباد؟"* أو *"اقترح تمرين نطق ممتع أثناء العشاء"*).
     - **نقطة قوة للمستثمر:** إبراز حماية الخصوصية (Zero-PII) حيث يتم إخفاء اسم الطفل تلقائياً قبل التواصل مع نموذج الذكاء الاصطناعي.
  5. **مكتبة التعلم المنزلي (`/parent/learning`):**
     - ميزة مستقبلية مصممة لاشتراكات B2C / عائلية إضافية تُعجب المستثمرين كفرصة نمو (Monetization).

#### المشهد الثالث: بوابة الأخصائي ومراجعة الفيديوهات (Specialist Deep-Dive)
- **تسجيل الدخول:** اضغط على تسجيل الخروج ثم ادخل كـ "أخصائي نطق (Speech Specialist)".
- **ما تعرضه للمستثمر:**
  1. **قائمة الأطفال المخصصين (`/specialist/children`):** رؤية الأطفال وحالة تقرير كل أخصائي.
  2. **ملف الطفل وإعداد التقرير (`/specialist/children/[id]`):**
     - استعراض التقرير الأولي الذي ولّده الذكاء الاصطناعي فور إكمال الاستبيان.
     - الضغط على تبويب "تقريري العيادي" واستعراض زر **«تحسين الصياغة بالذكاء الاصطناعي ✨»** لتحويل الملاحظات السريعة إلى تقرير طبي رصين.
  3. **مراجعة الفيديوهات المنزلية (`/specialist/reviews`):**
     - ادخل بحساب الأخصائي السلوكي `behavior@taawon.app`.
     - شاهد مقطع الفيديو المنزلي المرفوع من ولي الأمر، وقم بوضع تقييم (نجوم) وملاحظة توجيهية لولي الأمر لتحديث نسبة تقدم الطفل تلقائياً.

#### المشهد الرابع: بوابة المدير واعتماد الخطة الموحدة (Admin & AI Plan Synthesis)
- **تسجيل الدخول:** ادخل كـ "مدير المركز (Admin)".
- **ما تعرضه للمستثمر (The Core "Wow" Factor):**
  1. **لوحة المؤشرات (`/admin`):** مخططات الرادار وتوزيع كفاءة التأهيل عبر المركز.
  2. **دمج تقارير الفريق بخطة علاجية بالذكاء الاصطناعي (`/admin/plans/1`):**
     - افتح الخطة العلاجية المقترحة لطفل تجريبي.
     - اشرح للمستثمر كيف يقوم الـ AI Agent بدمج توصيات (أخصائي النطق + أخصائي السلوك + أخصائي التربية الخاصة) في **خطة علاجية موحدة لمدة 12 أسبوعاً** مع توليد مهام يومية للمنزل.
     - استعرض أزرار اتخاذ القرار:
       - **اعتماد الخطة فوراً** ونشر المهام لولي الأمر.
       - **إعادة التوليد بتوجيهات المدير** (نافذة تطلب من الـ AI Agent تعديل الخطة حسب ملاحظة المدير، مع حفظ سجل النسخ Versioning).
       - **إعادة التكليف للأخصائيين** لمزيد من الفحص.

#### المشهد الخامس: الأمان والاعتمادية (Enterprise Ready)
- وضح للمستثمر:
  - المنظومة تعمل بوضع **Fallback ذكي** (لو انقطع الإنترنت أو نفدت حصة الـ API، النظام يستجيب فورياً ببيانات عيادية واقعية دون أي خطأ).
  - الخصوصية التامة: أسماء الأطفال لا تخرج مطلقاً للذكاء الاصطناعي (PII Masking).
  - البنية البرمجية حديثة وجاهزة للإنتاج: Next.js 16 + Drizzle ORM + Turso/libSQL + Tailwind CSS v4.

### 4. النشر على الإنترنت للمستثمر (Deploy to Web on Vercel)

إذا رغبت في مشاركة رابط حي مباشر (URL) مع المستثمر:

1. **قاعدة البيانات السحابية (Turso / libSQL):**
   - افتح حساب مجاني على [Turso.tech](https://turso.tech).
   - أنشئ قاعدة بيانات:
     ```bash
     turso db create taawon-mvp
     turso db show taawon-mvp --url
     turso db tokens create taawon-mvp
     ```
   - ارفع المخطط والبيانات التجريبية:
     ```bash
     $env:DATABASE_URL="libsql://taawon-mvp-...turso.io"
     $env:DATABASE_AUTH_TOKEN="your-token"
     npm run db:push
     npm run db:seed
     ```

2. **النشر على Vercel:**
   - اربط المستودع في منصة Vercel.
   - أضف المتغيرات البيئية (Environment Variables):
     - `DATABASE_URL`: رابط قاعدة بيانات Turso
     - `DATABASE_AUTH_TOKEN`: توكن Turso
     - `AUTH_SECRET`: مفتاح تشفير عشوائي (مثال: `taawon-secret-investor-demo-2026`)
     - `GEMINI_API_KEY`: مفتاح Google Gemini (اختياري، إن لم يتوفر يعمل النظام تلقائياً ببيانات Demo عيادية واقعية بدون أي خلل).
